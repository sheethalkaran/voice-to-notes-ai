# Voice-to-Notes

Convert audio lectures or recordings into transcribed text, study notes, quizzes, and flashcards — powered by Google Gemini AI and a Gradio web app.

---

## Features

- Upload and transcribe any audio file (MP3, WAV, OGG, etc.)
- Automatically generate structured study notes
- Create custom quiz questions
- Generate flashcards for quick revision
- Export everything as a single PDF
